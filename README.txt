SPK PORTFOLIO — เว็บไซต์แฟ้มสะสมงานฝึกประสบการณ์วิชาชีพครู

วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP นี้
2. เปิดโฟลเดอร์ spk_portfolio
3. ดับเบิลคลิก index.html เพื่อเปิดเว็บไซต์ในเว็บเบราว์เซอร์

ไฟล์สำคัญ
- index.html : หน้าเว็บไซต์ทั้งหมด
- assets/profile.png : รูปโปรไฟล์ที่ได้รับจากผู้ใช้

การเผยแพร่เป็นเว็บไซต์ออนไลน์
- อัปโหลดทั้งโฟลเดอร์ขึ้นบริการ Static Hosting เช่น GitHub Pages หรือ Netlify
- ต้องคงโครงสร้างโฟลเดอร์ assets ไว้คู่กับ index.html
- ลิงก์ Google Drive ในเว็บไซต์จะเปิดได้เมื่อผู้ชมมีสิทธิ์เข้าถึงไฟล์/โฟลเดอร์นั้น

หมายเหตุ
- เว็บไซต์เป็นแบบ Responsive รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์
- ปุ่มเอกสารและคลังภาพเชื่อมไปยัง Google Drive ตามลิงก์ที่ผู้ใช้ให้มา
- ภาพกิจกรรมแสดงผ่านอัลบั้ม Google Drive เนื่องจากยังไม่มีไฟล์ภาพกิจกรรมแยกแนบมา
